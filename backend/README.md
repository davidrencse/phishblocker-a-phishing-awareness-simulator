# PhishBlocker Backend

This is the backend for PhishBlocker, a phishing awareness simulator.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Build the project:

   ```bash
   npm run build
   ```

3. Start the server:

   ```bash
   npm start
   ```

## Development

To start the server in development mode with auto-reloading, run:

```bash
npm run dev
```

## API

The API is versioned under `/api/v1`.

For more details about each endpoint, see [docs/api.md].
